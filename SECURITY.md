# Security policy

Please use GitHub's **Report a vulnerability** feature instead of a public issue. Include the affected version and a minimal plan that contains no production identifiers, rules of engagement, credentials, or collected evidence.

The supported release line is `0.1.x`. Unsafe parsing, report injection, unexpected network behavior, or bypasses of documented blocking checks are in scope.

This software checks plan consistency. It does not authorize an engagement or make execution safe by itself.
